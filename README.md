# Solar Systems AI — Platform Presentation

Public-facing presentation site for the **Solar Systems AI** platform — an intelligent infrastructure that handles repetitive computational tasks under strict governance, giving people back time for what matters.

## Overview

This site presents the platform's vision, architecture, principles, and current status to a general audience. It does not contain source code or implementation details of the platform itself.

**Live site:** [https://luizsolarsystems.github.io/solarsystems-pr](https://luizsolarsystems.github.io/solarsystems-pr)

## Tech Stack

- [Astro](https://astro.build) — Static site generator
- [Tailwind CSS](https://tailwindcss.com) — Utility-first CSS
- Bilingual: English + Portuguese (BR)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:4321/solarsystems-pr/](http://localhost:4321/solarsystems-pr/)

## Build

```bash
npm run build
npm run preview
```

## Deployment

Automatically deployed to GitHub Pages on push to `main` via GitHub Actions.
